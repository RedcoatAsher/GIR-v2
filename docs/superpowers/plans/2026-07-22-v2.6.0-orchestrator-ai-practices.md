Rule Authority Map governs placement: every new rule gets exactly one authoritative home; other files may reference, never restate.

**Tech Stack:** JSON manifests, Markdown files, git

**ADR:** `docs/decisions/2026-07-22-orchestrator-ai-practices.md` records the practice dispositions and contentious calls (orchestrator pin, executor non-pin, YAML schema, zero new skills, no METRICS.md, prompt-driven doctor).
